# RFC

RFC 是 Persisting 格式、所有权与存储契约的历史决策记录。它们保存已接受或
已提出的决策，不是命令参考。当前语法、schema 与支持的工作流见各产品的
Reference 和 Guides。

RFC 正文保持英文，因为它们是历史决策快照。翻译会产生两份可能漂移的副本。
