为什么选择 Persisting？

Persisting 把一次不稳定、带外部副作用的 Agent workload 封装成一个可执行、可中断、 可检查、可追溯、可批量编排的 Run。pVisor 负责单个 Run 的生命周期与隔离边界， pPilot 负责批量调度、恢复与 fencing，pChronicle 保存 canonical 事件历史。 隔离的强度按平台与 executor 如实记录在 Run Bundle；详细保证以 pVisor 隔离文档为准。

了解更多 → {% else %}

Why Persisting?

Persisting wraps an unreliable, side-effecting Agent workload into a Run that can be executed, interrupted, reviewed, traced, and orchestrated at scale. pVisor owns one Run's lifecycle and placement, pPilot schedules and recovers many, and pChronicle keeps the canonical event history. Isolation strength is reported honestly per platform and executor in the Run Bundle; consult the pVisor isolation documentation for the exact guarantees.

可审查的隔离

pvisor run --safe 创建 durable workspace，当前目录作为 OverlayFS lower， 写入暂存到 upper，并启用显式网络代理。Run Bundle 记录文件变更、网络拦截与安全警告。

Host、容器和 VM executor 的读写与网络边界不同。Run Bundle 分别记录实际安装的 文件系统和网络约束；精确的平台保证与已知缺口见 pVisor 隔离文档。

了解更多 → {% else %}

Reviewable Isolation

pvisor run --safe creates a durable workspace with the current directory as the OverlayFS lower, stages writes in the upper, and enables an explicit network proxy. The Run Bundle records filesystem changes, network interception, and safety warnings.

Host, container, and VM executors provide different filesystem and network boundaries. The Run Bundle records the controls actually installed; see the pVisor isolation documentation for platform-specific guarantees and known gaps.
