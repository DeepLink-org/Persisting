整体关系

可以组合，但不是强制流水线

pVisor 负责执行路径，pChronicle 负责历史路径。配置 capture 后，部分运行事件可以进入 pChronicle；外部轨迹也可以直接成为 Dataset。

{% else %}

HOW IT FITS TOGETHER

Composable, not a mandatory pipeline

pVisor owns the execution path; pChronicle owns the history path. Configured capture can connect selected runtime events to pChronicle, while external trajectories can enter as Datasets directly.
