保证必须具体

查看架构与成熟度 {% else %}

Guarantees must be specific

Filesystem confinement does not imply network isolation, capture does not imply non-bypassability, and lease fencing does not make arbitrary external APIs exactly-once. Persisting reports mechanisms and evidence per dimension in the Run Bundle.
