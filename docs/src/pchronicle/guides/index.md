# pChronicle guides

Start with [Query your first Dataset](../get-started.md), then choose a
task-oriented workflow.

1. [Discover and query a Dataset](discover-and-query.md).
2. [Import and export Runs](exchange.md).
3. [Serve Datasets locally](serve.md).
4. [Browse, drill down, and analyze in the local Web UI](ui.md).
5. [Forward, rewrite, and capture through the `serve` Gateway](serve-gateway.md).
6. [Capture a new Run with pVisor](../../pvisor/guides/capture.md).

The guides explain decisions and complete workflows. Use the
[`pchronicle` reference](../reference/cli.md) for exact flags, and
[Project examples](../../project/examples.md) for repository fixtures.

pChronicle owns durable history. Execution control belongs to pVisor.
