# Trajectory data and versions

Storyline is the normalized trajectory model used by the processing pipeline.
Import converts supported exchange formats into Storyline; storage and query
operate directly on that model. AgenticMD is its readable Markdown encoding.

A Snapshot pins Source membership and versions for one operation without
changing the identity of the original Source.

See [Dataset, Source, and Snapshot](dataset-and-source.md) and
[import/export](../guides/exchange.md).
